# Sleep Health & Lifestyle Analysis (EDA)

## 📊 Project Overview
This project provides a comprehensive **Exploratory Data Analysis (EDA)** on the relationship between lifestyle habits, health metrics, and sleep quality. Using a dataset of 374 individuals, I explored how factors like physical activity, stress levels, and occupation impact sleep disorders and overall sleep quality.

## 🛠️ Technical Skills Demonstrated
* **Data Cleaning & Preprocessing:** Handled missing values (imputation via mode) and performed feature engineering by splitting complex strings (Blood Pressure) into numeric components (Systolic/Diastolic).
* **Statistical Analysis:** Evaluated data distribution using **Skewness** and identified outliers via **Boxplots**.
* **Advanced Visualization:** Leveraged `Seaborn` and `Matplotlib` to create Heatmaps, Pairplots, and KDE plots to visualize multi-dimensional relationships.

## 🔍 Key Insights from the Data
* **Stress vs. Sleep:** A strong negative correlation was observed between stress levels and the quality of sleep.
* **Occupational Impact:** Different professions show varying distributions of sleep duration and disorders.
* **Health Metrics:** Higher heart rates and daily steps showed specific distribution patterns that influence sleep hygiene.

## 🚀 Future Work
My next step for this project is to build a **Machine Learning model** to predict sleep quality based on the health features analyzed in this EDA.
